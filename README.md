# مَشهَدآية — استوديو الآيات القرآنية

تطبيق يحوّل معنى الآية إلى **مشهد متحرك صامت يُفهم بالنظر**، ويعرض معه نصّ الآية بالرسم العثماني والتفسير الميسّر، وتقريرًا يبيّن ما رُسم وما تُرك ولماذا. يعمل على **أندرويد** و**ويندوز** والمتصفح من شيفرة واحدة.

## ماذا في التطبيق؟

- **صفحة الهبوط**: `index.html` — تعريف بالتطبيق مع عرض حيّ للمشاهد وروابط التنزيل. تُنشر تلقائيًا على GitHub Pages مع التطبيق (`app.html`).
- **ترجمة معاني الآيات**: بالإنجليزية والفرنسية والإندونيسية والتركية والأردية، من QuranEnc.com دون تعديل، وتعمل دون إنترنت (تُختار من الإعدادات).
- **المفضّلة وآخر ما شوهد**: زر ♥ في كل مشهد، ويظهر القسمان أعلى المكتبة.
- **اختبر فهمك**: لعبة يُعرض فيها مشهد دون شرح، ويختار اللاعب الآية التي يصوّرها من ثلاث آيات، مع عدّاد للنتيجة.
- **التلاوة مع المشهد**: تُسمع الآية مرتّلة بصوت أحد أربعة قرّاء، ويمتد المشهد على طول التلاوة، وتدخل التلاوة في الفيديو المحفوظ. الصوت يُبثّ من quran.com (والاحتياطي everyayah.com) فيحتاج إنترنت.
- **الوضع السينمائي** (الافتراضي): لكل لقطة صورة سينمائية واقعية أو بأسلوب الأنمي، تُحرَّك بحركة كاميرا بطيئة وانتقالات وتدرّج لوني وحبيبات فيلم وشريطين أسودين، ويُرسم فوقها المطر والبرق.
  - لقطات المكتبة مولَّدة مسبقًا (`scripts/gen-shots.mjs`) ومراجَعة بالنظر، ومضمَّنة في التطبيق: تعمل فورًا ودون إنترنت وتدخل في الفيديو المحفوظ.
  - بقية المشاهد وآيات الاستوديو تُولَّد مباشرة من خدمة Pollinations المجانية (لقطة كل ٤٦ ثانية، وعلامة الخدمة في الزاوية)، **بشرط مفتاح Claude**: المراجع الشرعي يفحص كل صورة قبل عرضها، لأن الخدمة أخرجت في التجربة صورًا غير محتشمة رغم القيود. دون مفتاح تُعرض هذه المشاهد بالرسوم.
  - الوصف يُبنى من عناصر المشهد لا من نص الآية، ويمنع دائمًا الملائكة والأجنحة على البشر والهالات والشخصيات الدينية، ويطلب «لا أحد» حين لا يكون في اللقطة شخص.
  - لإكمال لقطات المكتبة لاحقًا: `node scripts/gen-shots.mjs real 5` (يكمل الناقص فقط)، ثم راجع الصور بالنظر وأضف المرفوض إلى `scripts/rerolls.json` واحذف ملفه.
- **انفعالات وأقوال**: الشخصيات تفرح وتحزن وتخاف وتندهش وتغضب، بتعابير الوجه ولغة الجسد، وتقول ما تذكره الآية في فقاعات كلام (عادي، صراخ، همس).
- **أصوات الطبيعة**: مطر ورعد يلي البرق وريح وبحر وطير، تُولَّد بالكود وتُخفَّض تلقائيًا مع التلاوة.
- **شخصيات أنمي**: ناس وأنعام (إبل، بقر، غنم، ماعز) وطير، تُرسم بالكود في درجة «متساهل» فقط، وتُحذف آليًا في الدرجتين الأخريين. لا يُرسم نبي ولا ملَك.
- **المكتبة**: ٣٦ مشهدًا مُعدًّا يدويًا لآيات كونية وأمثال قرآنية (إحياء الأرض الميتة، سبع سنابل، صفوان عليه تراب، كسراب بقيعة، كيف مدّ الظل، فالق الحب والنوى، شجرة خبيثة اجتُثّت…).
- **ربط اللقطة باللفظ**: أثناء العرض يُظلَّل في نصّ المصحف اللفظُ المقابل لكل لقطة. الربط يُفحص آليًا: `npm run check` يتأكد أن كل لفظ مربوط موجود حرفيًا في الآية (١٦٦ لقطة).
- **البحث في المصحف**: اكتب كلمة (مطر، النخل، الجبال…) في الاستوديو فتظهر الآيات التي فيها، وبضغطة يُبنى مشهدها.
- **حفظ فيديو**: زر في المشغّل يسجّل المشهد كاملًا مع شروحه فيديو (WebM بدقة 1280×720) لمشاركته. متاح في المتصفح وويندوز، وليس في تطبيق أندرويد.
- **الاستوديو**: اختر أي آية من المصحف، فيعمل عليها أربعة وكلاء بالتتابع:

| الوكيل | عمله |
|---|---|
| جامع التفسير | يستخرج المعنى والمحسوسات المرئية من التفسير الميسّر المضمَّن |
| المراجع الشرعي | يطبّق الضوابط **قبل** الرسم (هل تُصوَّر الآية أصلًا؟) و**بعده** (فحص المشهد النهائي) |
| الرسّام | يؤلّف المشهد من مفردات كونية محدّدة |
| المحرّك | يرتّب الحركة والشروح على ترتيب المعاني في الآية |

  - **دون اتصال** (الافتراضي): وكلاء بالقواعد، متحفّظون عمدًا، يعملون بلا إنترنت.
  - **بالذكاء الاصطناعي** (اختياري): أدخل مفتاح Anthropic API في الإعدادات فيعمل الوكلاء بـ Claude، ثم يمرّ ناتجهم على التنقية والفحص الآلي نفسه.

## درجة المراجع الشرعي

تُختار من «الضوابط والإعدادات» في التطبيق، والافتراضي **متساهل**:

| الدرجة | متى يُبنى المشهد |
|---|---|
| متساهل | لكل آية تقريبًا، مع شخصيات أنمي للناس والأنعام والطير: يُترك من المشهد ما لا يُرسم وتُرسم البقية، وإن لم يكن في الآية محسوس رُسم مشهد عام هادئ يرافق التفسير |
| معتدل | إذا كان في الآية محسوس كوني، ويُمنع ما يدور على الغيب أو الصفات |
| متشدّد | الآيات الكونية الصريحة فقط، ويُمنع عند أي ذِكر لنبي أو ملَك أو غيب |

في كل الدرجات لا يُرسم نبي ولا ملَك ولا غيب.

## الضوابط الشرعية

1. لا تُصوَّر ذات الله تعالى ولا صفاته، ولا يُرمز لها.
2. لا يُصوَّر الأنبياء ولا الملائكة ولا الصحابة.
3. لا يُصوَّر الغيب (الجنة، النار، البعث، الجنّ…).
4. الإنسان والحيوان والطير في درجة «متساهل» فقط، شخصياتٍ عامة لا تمثّل أحدًا.
5. يُرسم المشبَّه به والآية الكونية فقط، بلا زيادة على التفسير.
6. نصّ الآية يُعرض من المصحف كما هو خارج الرسم.
7. المشهد وسيلة إيضاح وليس تفسيرًا.

الضمانة بنيوية: محرّك الرسم (`src/engine/render.js`) لا يملك عنصرًا للغيب، والشخصيات (`src/engine/figures.js`) تُحذف خارج «متساهل»، وكل مشهد مولَّد يمرّ على قائمة بيضاء وفحص آلي (`src/agents/rules.js`). **ومع ذلك فهذا عمل برمجي يحتمل الخطأ؛ اعرض المشاهد المولَّدة على طالب علم قبل نشرها أو تعليمها.**

## التشغيل والبناء

```bash
npm install
npm run dev                 # نسخة الويب للتطوير (الهبوط على / والتطبيق على /app.html)
npm run check               # فحص دقة المشاهد وربطها بألفاظ الآيات
npm run desktop             # تشغيل نسخة سطح المكتب
npm run dist:win            # مثبّت ويندوز (على ويندوز، أو عبر GitHub Actions)
npm run dist:win:portable   # نسخة ويندوز محمولة zip (تُبنى من لينكس)
npm run dist:android        # APK موقَّع — بلا Android Studio ولا Gradle
```

كل دفع إلى `main` يبني مثبّت ويندوز و APK في **GitHub Actions** وينشر صفحة الهبوط على Pages. وحين يتغيّر رقم `version` في `package.json` يُنشر إصدار جديد في صفحة Releases تلقائيًا، فيظهر للمستخدمين تنبيه «نسخة جديدة متاحة» داخل التطبيق.

## إصدار تحديث

1. غيّر `version` (ووصفًا قصيرًا في `releaseNotes`) في `package.json`.
2. ادفع إلى `main`. هذا كل شيء: الموقع يتحدّث، ويُنشر `version.json` الذي تقرؤه النسخ المثبّتة، ويُنشأ الإصدار بملفّيه.

يمكن أيضًا دفع وسم يدويًا:

```bash
git tag v1.1.0
```

```bash
git push origin v1.1.0
```

**توقيع أندرويد:** السكربت يولّد مفتاحًا في `android/release.p12` إن لم يوجد. احتفظ بمفتاحك الخاص (ولا ترفعه للمستودع) حتى تستطيع تحديث التطبيق فوق النسخة المثبتة؛ وفي GitHub ضعه في السرّين `ANDROID_KEYSTORE_BASE64` و `ANDROID_KEYSTORE_PASS`.

```
index.html              صفحة الهبوط (src/landing.js)     app.html  التطبيق (src/main.js)
src/engine/render.js    محرّك المشاهد (Canvas): ٢٨ عنصرًا كونيًا + كاميرا + مشغّل
src/words.js            مطابقة ألفاظ الآية بنصّ المصحف
src/engine/figures.js   شخصيات الأنمي: ناس وأنعام وطير
src/audio.js            التلاوة: قرّاء، تحميل، مزامنة، دمج في الفيديو
src/cinema.js           الوضع السينمائي: أوصاف اللقطات، التوليد، الإخراج، مراجعة الصور
public/cine/            لقطات المكتبة المولَّدة مسبقًا
src/scenes/library.js   المشاهد المُعدّة يدويًا
src/agents/rules.js     الضوابط، القائمة البيضاء، الفحص الآلي
src/agents/offline.js   الوكلاء دون اتصال

electron/               غلاف ويندوز      android/  غلاف أندرويد وسكربت البناء
```
